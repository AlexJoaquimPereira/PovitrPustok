## Upgrade test

Previous release: **v1.2.4** (tag `ca9ff5a`, versionCode 10, APK Signature Scheme v2, same signer
certificate). Built from the tag with the release keystore and the private corpus.

1. Uninstalled the app and installed the v1.2.4 release APK on the API 35 emulator.
2. Opened **Bible → Utpoti (Genesis) → chapter 1**.
3. Selected verse 1 and added a bookmark (`Bookmarked · Utpoti 1:1`); the bookmark was listed.
4. Installed the 1.3.0 APK over it with `adb install -r` (no uninstall, versionCode 11 over 10).
5. Launched the app: the home screen showed **Continue reading — Utpoti, 1 minute ago**;
   Bookmarks still listed **Utpoti (Genesis) 1:1**; opening it returned to Genesis 1 with
   **Remove bookmark** shown.

**Result: pass.** The Room v2→v3 anchor migration preserved bookmarks and reading state on a real
in-place upgrade.
